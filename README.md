## 💻 Como Executar o Projeto

Para visualizar ou testar os exemplos desta aula, siga os passos abaixo:

### 1. Clonar o Repositório
Abra o seu terminal e execute o seguinte comando:

```bash
git clone [https://github.com/deilsongilmar-web/Aula-07.git](https://github.com/deilsongilmar-web/Aula-07.git)
````

### 2\. Navegar até a Pasta

Entre no diretório do projeto:

```bash
cd Aula-07
```

### 3\. Abrir o Projeto

Como se trata de um projeto de desenvolvimento [Web], você pode simplesmente abrir o arquivo principal (`index.html` ou similar) no seu navegador.

> **Dica:** Se estiver usando o VS Code, utilize a extensão **Live Server** para abrir o projeto, pois ela garante que todos os scripts sejam carregados corretamente, especialmente para requisições assíncronas (se houver).
